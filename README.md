# ADCAD 2D — protótipo para Windows

Aplicativo CAD 2D em Python e PySide6. Ferramentas: linha, polilinha, círculo, retângulo, apagar, desfazer, zoom, abrir/salvar DXF e exportar PDF.

## Executar
Instale Python 3 no Windows, extraia o ZIP e execute `INICIAR.bat`.

## Gerar EXE
Execute `CRIAR_EXE.bat` em um computador Windows. O executável será gerado na pasta `dist`.

Este é um protótipo inicial, não uma implementação completa do AutoCAD/GstarCAD.
